# Cloudflare Zero Trust Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement Cloudflare Zero Trust across 4-node Kubernetes cluster with complete traffic separation, authentication, and audit logging

**Architecture:** Dual-path (public bypass + private authenticated) using cloudflared tunnels on master node, WARP client for SSH/kubectl access, Gateway policies for infrastructure access control

**Tech Stack:** Cloudflare Zero Trust (Tunnels, Access, WARP, Gateway), cloudflared daemon, iptables, systemd

### Task 4: Configure Cloudflared Tunnel

**Files:**
- Create: `/etc/cloudflared/config.yml`

- [ ] **Step 1: Create config.yml**

```bash
sudo tee /etc/cloudflared/config.yml > /dev/null <<'EOF'
tunnel: goalixa-cluster
credentials-file: /etc/cloudflared/tunnel-credentials.json

ingress:
  # Public services (no authentication)
  - hostname: goalixa.com
    service: http://localhost:80
    originRequest:
      noTLSVerify: true
      connectTimeout: 30s

  - hostname: app.goalixa.com
    service: http://localhost:80
    originRequest:
      noTLSVerify: true
      connectTimeout: 30s

  # Private services (Access enforced by Cloudflare)
  - hostname: argocd.goalixa.com
    service: http://localhost:80
    originRequest:
      noTLSVerify: true
      connectTimeout: 30s

  - hostname: harbor.goalixa.com
    service: http://localhost:80
    originRequest:
      noTLSVerify: true
      connectTimeout: 30s

  - hostname: monitoring.goalixa.com
    service: http://localhost:80
    originRequest:
      noTLSVerify: true
      connectTimeout: 30s

  # Catch-all rule (required)
  - service: http_status:404

warp-routing:
  enabled: false

loglevel: info
logfile: /var/log/cloudflared.log
metrics: 0.0.0.0:2000
EOF
```

### Task 5: Create Systemd Service for cloudflared

**Files:**
- Create: `/etc/systemd/system/cloudflared.service`

- [ ] **Step 1: Create systemd service file**

```bash
sudo tee /etc/systemd/system/cloudflared.service > /dev/null <<'EOF'
[Unit]
Description=Cloudflare Tunnel
After=network.target

[Service]
Type=simple
User=root
ExecStart=/usr/bin/cloudflared tunnel --config /etc/cloudflared/config.yml run
Restart=on-failure
RestartSec=5s
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

### Task 33: Create Firewall Lockdown Script

**Files:**

- [ ] **Step 1: SSH to master node**

```bash

```

- [ ] **Step 3: Create firewall script**

```bash
cat > /root/cloudflare-firewall.sh <<'EOF'
#!/bin/bash
# Cloudflare Zero Trust Firewall Lockdown
# This script closes SSH (22) and kubectl (6443) ports to public internet
# Access only allowed through WARP tunnel

set -e

echo "Starting Cloudflare Zero Trust firewall lockdown..."

# Backup current rules
echo "Backing up current iptables rules..."
iptables-save > /root/iptables-backup-$(date +%Y%m%d-%H%M%S).txt

# Keep existing chains and policies intact
# Only add rules for SSH and kubectl lockdown

# Block SSH from public (port 22)
echo "Blocking SSH port 22 from public internet..."
# Allow established connections (don't break current SSH session)
iptables -I INPUT -p tcp --dport 22 -m state --state ESTABLISHED,RELATED -j ACCEPT
# Drop new SSH connections
iptables -A INPUT -p tcp --dport 22 -j DROP

# Block kubectl from public (port 6443)
echo "Blocking kubectl port 6443 from public internet..."
# Allow established connections
iptables -I INPUT -p tcp --dport 6443 -m state --state ESTABLISHED,RELATED -j ACCEPT
# Drop new kubectl connections
iptables -A INPUT -p tcp --dport 6443 -j DROP

# HTTP/HTTPS remain open (ports 80, 443) for nginx-ingress
echo "Ports 80 and 443 remain open for nginx-ingress..."

# Make rules persistent
echo "Saving iptables rules..."
if command -v netfilter-persistent &> /dev/null; then
    netfilter-persistent save
elif [ -f /etc/iptables/rules.v4 ]; then
    iptables-save > /etc/iptables/rules.v4
else
    echo "Warning: Could not find persistence method"
    echo "Rules will be lost on reboot"
fi

echo ""
echo "Firewall lockdown complete!"
echo ""
echo "Current iptables rules for ports 22 and 6443:"
iptables -L INPUT -n -v | grep -E "(22|6443)"
echo ""
echo "IMPORTANT: SSH and kubectl now only accessible via WARP tunnel"
echo "Emergency access: Use hosting provider console"
EOF
```

Expected: Script created

- [ ] **Step 4: Make script executable**

```bash

#!/bin/bash
# Monitor cloudflared tunnel health

LOG_FILE="/var/log/cloudflared-health.log"

# Check if service is running
if ! systemctl is-active --quiet cloudflared; then
    echo "$(date): ERROR - cloudflared service is not running" >> $LOG_FILE
    systemctl restart cloudflared
    echo "$(date): Service restarted" >> $LOG_FILE
    exit 1

# Check metrics endpoint
if ! curl -s http://localhost:2000/metrics > /dev/null; then
    echo "$(date): ERROR - cloudflared metrics endpoint not responding" >> $LOG_FILE
    systemctl restart cloudflared
    exit 1
fi

# Check for connection errors in logs
ERRORS=$(journalctl -u cloudflared --since "5 minutes ago" | grep -i error | wc -l)
if [ $ERRORS -gt 5 ]; then
    echo "$(date): WARNING - $ERRORS errors in last 5 minutes" >> $LOG_FILE
fi

# Log healthy status every hour
MINUTE=$(date +%M)
if [ "$MINUTE" == "00" ]; then
    echo "$(date): Tunnel healthy" >> $LOG_FILE
fi
EOF

chmod +x /root/check-cloudflared-health.sh
```
